# Limitations and Responsible Interpretation

- All data is synthetic and tuned to create a diagnostic scenario; the project
  demonstrates method, not a finding about a real company.
- Last-non-direct attribution assigns credit; it does not estimate causal lift.
- Visitor identifiers are cleaner than real browser and cross-device identity.
- Ninety-day net revenue is realized cohort value, not modeled lifetime value.
- Comparisons must use mature trial, rebill, and revenue cohorts.
- A tracking divergence can narrow the likely failure domain but cannot prove a
  specific technical root cause without tag, deployment, consent, and server
  logs.
- Campaign economics exclude payroll, vendor fees, overhead, and other costs;
  ROAS is not profit.
- Tableau Public is appropriate only because every row is synthetic.
